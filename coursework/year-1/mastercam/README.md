## Classroom context

In class, I programmed 3 axis milling operations, made toolpaths, ran simulations, and created NC programs. We did not run our class programs on a real CNC machine. The files show the programming and simulation work I completed.

## Workflow demonstrated

1. Create or import part geometry.
2. Define stock, tools, work offsets, planes, and machining operations.
3. Calculate and verify toolpaths.
4. Organize one or more machining setups.
5. Turn the operations into NC code for a controller.
6. Review the posted program as readable text.

## Toolpath simulation

The animation shows the milling tool moving toward the stock and starting the operation. I used simulation to check the tool direction, stock setup, and machine movement.

## Applied CNC experience

I later got real machining experience while interning at the **NYC FIRST STEM Center at Roosevelt Island**. I made CAM operations, posted my own G code, checked the programs, and ran them on CNC machines. This helped me use the 3 axis programming skills from class on real equipment.

The earlier vendor/course reference directory was intentionally removed and is not included in these counts. `.emcam` files may require a compatible educational Mastercam installation.

> **Manufacturing safety:** Never run archived NC code directly on a machine. Verify the controller, post processor, tooling, workholding, stock, offsets, feeds, speeds, and clearance moves first.
