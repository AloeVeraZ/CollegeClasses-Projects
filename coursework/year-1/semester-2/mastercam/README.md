# Mastercam — Semester 2

A CAD/CAM and CNC-programming archive containing **357 files (360.49 MiB)**.

## Student tutorial work

`Tutorial 1/` through `Tutorial 7/` contain educational Mastercam projects. Tutorials 1–6 also retain posted NC programs and, where available, text copies for review. Tutorial 4 includes three setup outputs, showing a multi-setup workflow.

The files demonstrate the path from CAM project to posted machine code:

1. Create or import geometry.
2. Define stock, tools, planes, and machining operations.
3. Verify toolpaths and setup order.
4. Post the operations to `.NC` output.

## Reference material

`Tutorial FIles/` contains Mastercam 2022 exercise and supporting assets for beginner, lathe, 2D mill, 3D mill, advanced mill, and multiaxis work. These include Mastercam projects, SolidWorks and Parasolid geometry, STEP files, machine/control definitions, post files, and tool data. They are retained as course context and are not claimed as original student-created assets.

`.emcam` educational files may require an educational Mastercam installation. Never run posted NC code directly on a machine: verify it against the intended controller, post processor, stock, offsets, tooling, and workholding first.
