# MECH 1101 — Machine Shop

> Hands-on introduction to layout, manual machining, bench work, inspection, and collaborative manufacturing practice.

| Course evidence | Details |
| --- | --- |
| **Project** | [Project #1 — Machined Plate](project-1/README.md) |
| **Media** | 13 progress photographs and 1 inspection sheet |
| **Processes** | Layout, drilling, tapping, reaming, countersinking, counterboring, cutting, filing, sanding, and inspection |

## Learning outcomes demonstrated

- Translate a drawing and dimensions into physical layout marks.
- Select and sequence drilling and hole-finishing operations.
- Produce threaded, reamed, countersunk, and counterbored features.
- Remove material to a scribed line using manual processes.
- Inspect finished dimensions against nominal values and tolerances.
- Document work across multiple shop sessions as part of a team.
