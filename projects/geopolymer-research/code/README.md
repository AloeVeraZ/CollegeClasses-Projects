## Safety

The pin assignments, serial identifiers, dimensions, current limits, temperature behavior, and motion parameters are specific to the research printer. Do not deploy the configuration to another machine without validating the hardware, wiring, endstops, thermal protections, clearances, and emergency-stop procedure.
